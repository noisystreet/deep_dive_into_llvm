欢迎来到 **浅入深出 LLVM** ！本书旨在帮助读者系统性地理解 LLVM 编译器基础设施的内部设计与实现。

为什么要写这本书？
========================

LLVM 是当代编译器基础设施的标杆。它不仅支撑着 Clang、Rustc、Swift 等主流编译器前端，更是无数研究项目和工业工具的核心基石。从 Apple 的 Xcode 到 NVIDIA 的 CUDA 编译器，从 Python 的 Numba 到 Julia 的 JIT 编译——LLVM 的身影无处不在。

然而，LLVM 的代码量庞大、架构复杂，官方文档虽然详尽但更偏重 API 参考，对内部实现机制的系统性讲解相对分散。本书的写作目标正是填补这一空白：

- **梳理架构全貌** ：将 LLVM 的各层组件（IR、Pass 框架、CodeGen、JIT 等）串联成一条完整的故事线
- **深入关键实现** ：通过源码分析，揭示指令选择、寄存器分配、优化通道等核心环节的实现细节
- **配套可运行示例** ：每个关键概念都配有最小化可运行示例，让理论落地

目标读者
============

本教程面向：

- 有一定 C/C++ 使用经验，想了解 LLVM 内部工作原理的开发者
- 对编译器技术感兴趣的读者
- 希望为 LLVM/Clang 贡献代码或自定义后端的开发者
- 从事编程语言设计、希望对接到 LLVM 基础设施的技术人员

预备知识
============

阅读本书前，建议读者具备：

1. **C/C++ 基础** ：熟悉 C/C++ 语言语法和编译流程，能读懂基本的 C++ 代码
2. **数据结构基础** ：了解图、树、DAG 等基本数据结构
3. **编译原理基础** （可选）：了解词法分析、语法分析、中间表示、目标代码生成等基本概念会有所帮助，但不是必须的

如何阅读
============

- **按顺序阅读** ：本书章节按知识递进关系组织，建议从第 1 章开始顺序阅读
- **动手实践** ：每章包含代码示例，建议在本地环境中实际编译运行
- **深入源码** ：文中会引用 LLVM/Clang 源码的特定位置，建议结合源码对照阅读
- **使用附录** ：附录中包含关键代码阅读指南和术语表，阅读中遇到不熟悉的术语可随时查阅

环境说明
============

本书示例基于以下环境：

- **操作系统** ：Linux x86_64
- **LLVM/Clang** ：22.x（``llvmorg-22.1.8`` ）
- **构建工具** ：CMake >= 3.20，Ninja 或 Make

.. note::

   本书示例在 Linux 平台上开发和测试。macOS 和 Windows 用户可通过 WSL2 或 Docker 获得相同的实验环境。
